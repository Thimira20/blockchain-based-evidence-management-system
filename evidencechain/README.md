# EvidenceChain

**Blockchain-Based Digital Forensic Evidence Integrity & Chain-of-Custody System**

A blockchain-based evidence management system where investigators record digital evidence (files, logs, images) as tamper-proof hash records on Ethereum. Custody transfers must be logged by the current holder and confirmed by the receiving party, which prevents undetected tampering and disputes over who handled the evidence and when. Courts and auditors can instantly verify that evidence is unaltered and review its complete custody history before it's admitted as proof.

Built for **EC8204 Blockchain and Cyber Security**, University of Ruhuna.

---

## Prerequisites

- Node.js **v18+** (v20/22 LTS recommended)
- npm v9+
- A Chromium-based browser (Chrome or Edge)
- No internet connection is required once `npm install` has completed — everything else runs fully offline on your own machine.

## Install

```powershell
cd evidencechain
npm install
```

## Run it (every time)

Restarting the Hardhat node **wipes the blockchain**, so `deploy` and `seed` must be run again after every node restart.

```powershell
# Terminal 1 — keep running (the local blockchain)
npm run node

# Terminal 2 — deploy the contract and load demo data
npm run deploy
npm run seed

# Terminal 3 — keep running (the website)
npm run frontend
```

Then open **http://localhost:8080** in your browser (must be `localhost`, not a LAN IP — the browser's file-hashing feature only works on a secure/local origin).

## Run the tests

```powershell
npm test              # 25 tests, all should pass
npx hardhat coverage   # statement/branch/function/line coverage report
```

Current result: **25/25 tests passing**, **100% statement, function and line coverage** (branch coverage 70%, from defensive `require` conditions that a demo does not need to exercise both sides of).

## How to use the app — a quick walkthrough

1. Open http://localhost:8080. The header shows whether you're connected to the local blockchain.
2. Use the **"Act as"** dropdown to switch between people: Admin, Det. Perera (Investigator), Forensic Analyst Silva (Analyst), Evidence Room officer (Custodian), Magistrate Court (Court), or Public/Outsider.
3. As **Det. Perera**, go to **Register Evidence**, pick a file from `sample-evidence/`, fill in a Case ID, and click Register. The browser computes the file's SHA-256 fingerprint locally — the file itself is never uploaded anywhere.
4. Go to **Transfer Custody** to hand the evidence to someone else. The other person must switch to their account and **accept** it from the Dashboard's "Incoming Transfers" box before the handover completes.
5. Go to **Verify Integrity**, pick the same file again, and check it shows **AUTHENTIC**. Try `suspect_chat_log_TAMPERED.txt` instead and watch it show **TAMPERED**.
6. As **Magistrate Court**, once holding a piece of evidence, verify it and click **Admit as Evidence** to close its lifecycle.
7. Go to **Custody History** to see the full, permanent timeline for any evidence ID.

## Troubleshooting

| Symptom | Fix |
|---|---|
| "Not connected" banner | Start `npm run node`, then `npm run deploy` and `npm run seed` again |
| Contract calls fail after restarting the node | Run `npm run deploy` and `npm run seed` again, then hard-refresh the browser (Ctrl+F5) |
| "crypto.subtle is undefined" | Open the app via `http://localhost:8080`, not `file://` or a LAN IP |
| Hash doesn't match `Get-FileHash` | The file was edited/re-saved. Use the original file, never re-save sample files |
| "Evidence already registered" during a rehearsal | The chain still has it from a previous run — restart the node, deploy and seed again |
| Port 8545 or 8080 already in use | `Get-NetTCPConnection -LocalPort 8545` (or 8080) to find the process, then stop it |
